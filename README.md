# Personal Portfolio Website

This project is a clean, minimalist portfolio site built with plain HTML and CSS for GitHub Pages deployment.

## Files

- index.html — Main page structure and content
- style.css — Responsive styling and layout
- resume.pdf — Downloadable resume file

## Where to place files

- Place the PDF resume at the site root as resume.pdf so the download button works correctly.
- If you want to add a profile image, place it at the site root as profile.jpg and update the hero section to include it.
- For project screenshots, place them in a folder such as images/ and reference them from the relevant project cards.

## Deployment

1. Upload these files to the root of your GitHub Pages repository.
2. Ensure the repository contains index.html, style.css, and resume.pdf.
3. Enable GitHub Pages from the repository settings.

## Notes

The site is designed to be simple, accessible, and easy to maintain. It uses semantic HTML and responsive CSS only, with no frameworks or JavaScript required.
